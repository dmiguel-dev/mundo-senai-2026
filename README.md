# Mundo SENAI 2026 - Áreas de Atuação em TI

Apresentação desenvolvida para o evento **Mundo SENAI 2026** abordando as principais carreiras e áreas da Tecnologia da Informação:
* Desenvolvimento de Software
* Infraestrutura e Redes
* Computação em Nuvem
* Cibersegurança
* Ciência de Dados
* Garantia de Qualidade (QA)
* UX/UI Design
